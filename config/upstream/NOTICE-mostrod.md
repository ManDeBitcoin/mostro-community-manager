# mostrod

This image contains the official, unmodified `mostrod` binary released by the
Mostro project, downloaded from its GitHub release and verified by SHA-256.

- Version: 0.19.2
- License: GPL-3.0-or-later (see `LICENSE` in this directory). Code contributed
  before the relicense keeps the MIT notice in `LICENSE-MIT`.
- Corresponding source: https://github.com/MostroP2P/mostro/tree/v0.19.2
- Release and checksums: https://github.com/MostroP2P/mostro/releases/tag/v0.19.2

Mostro Community Manager runs `mostrod` as a separate process and talks to it
only through its configuration file and the Nostr protocol.
